## The publish loop (Windows PowerShell)

```powershell
cd "B:\Dropbox (Personal)\Personal Files\personal_web_2026\ruidai-site"
python build.py                          # regenerates docs/  (needs: pip install pyyaml markdown)
git add -A; git commit -m "what changed"; git push
```

Live about a minute after the push. Images on the live site are cached ~10 min; Ctrl+F5 if stale.

| Want to change… | Edit |
|---|---|
| a paper, coauthor, R&R note, award | `content/papers.yml` (see README for the field list) |

## Design decisions (so we don't relitigate them)

- **Self-contained pages.** Fonts, images, and the D3 subset are embedded in the HTML — no CDN,
  no Google Fonts requests. Done so the site renders in mainland China (jsDelivr and Google are
  blocked/unreliable there) and when opened as a local file. Pages are ~480–500 KB each; fine.
- **GitHub Pages, not a VPS.** Free, no maintenance. From mainland China `github.io` is reachable but
  slow/intermittent. If a Shenzhen colleague finds it too slow, options are a Gitee Pages mirror or a
  Hong Kong static host under the same domain; a US VPS (Linode etc.) would not help.
- **Research page defaults to the FT50 tab.** All / UTD24 / Other are one click away.
- **Coauthor graph** sits on a warm parchment panel (`#e9e6de`) like all other tiles; nodes have soft
  blurred edges; the graph ignores the journal-list tab (so it's fully lit on load) and only dims when a
  topic / author / search filter is active. Hub node is ink-coloured.
- **All dark panels unified** to the parchment tone (project tiles, sketch placeholders, footer).
- **Impact stats** (Scholar citations, h-index, SSRN downloads, "as of" month) sit at the top of the
  Research page, above the Publications heading. They were tried on the home page and removed — the
  home page is name, roles, bio, three links only. No email link in the top nav or link row; the CONTACT
  icon at the bottom of the home page still opens mail.
- **Phone layout** of the home page: portrait as a dim full-screen backdrop behind the text (the
  original design). A "portrait header on top, text below" variant was tried and rejected.
- **Cache-busting query strings were removed** — they broke images when the page is opened as a local
  file on Windows. Tile images are embedded instead.
- **Working papers under R&R** are noted with a badge (e.g. "R&R, Journal of Banking & Finance") rather
  than a separate status; `status` stays `Working paper`.

## Known quirks / gotchas

- Git in the Dropbox folder, when driven from Claude's device bridge, can't delete its own lock files;
  they get moved to `personal_web_2026\_to_delete\git-tmp\`. That folder is safe to delete any time.
  Committing from your own PowerShell has no such issue.
- `update_stats.py`: SSRN fetch works; Google Scholar often blocks scripts — it then keeps the old number
  and says so; edit `stats.yml` by hand in that case (or ask Claude to read the live number via Chrome).
- The GitHub fine-grained token used for the initial push should be deleted (GitHub → Settings →
  Developer settings → Fine-grained tokens → `cowork-launch`) if it hasn't been already.
